# 🌧️ Smart Rain — Marketing Website

A responsive marketing website for **Smart Rain**, an IoT-based automated
rainwater and irrigation management system.

The website presents the Smart Rain concept, its core features, and the
technology behind the system through a clean and accessible product experience.

🌐 **[View Live Website](https://smart-rain-akshaya.vercel.app/)**

---

## 🌱 About Smart Rain

Smart Rain was developed as part of my Bachelor of Digital Technology
industry project.

The wider Smart Rain system explores how IoT technology, real-time data,
automation, and weather information can be used to improve rainwater
management and irrigation decisions.

Core capabilities of the wider system include:

- 💧 Real-time water-level monitoring
- ⚙️ Automated pump management
- 🌦️ Weather-data integration
- 📊 System monitoring and visualisation
- 🔐 User authentication
- 📡 Configurable sensor integration

> This repository contains the **public-facing marketing website** for
> Smart Rain. Other components of the Smart Rain system are maintained
> separately.
